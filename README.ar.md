> *مستوحاة من حركة "البرمجة بالأجواء" (Vibe Coding) من المطورين... نحن نوسع الكون: **التسويق بالأجواء** (Vibe Marketing) لعصر الذكاء الاصطناعي حيث يعمل كل شيء بسلاسة.*

| | |
|---|---|
| **مع الذكاء الاصطناعي** | دع وكلاء الذكاء الاصطناعي يتولون حملاتك بينما تركز أنت على الاستراتيجية. فقط استرخِ ودع الوكلاء يقومون بالعمل الشاق. |
| **بدون الذكاء الاصطناعي** | هذا المستودع هو **مكتبة مرجعية شاملة** لأفضل الممارسات التسويقية والأطر والقوالب. استخدم وثائق المهارات كدليل تسويقي لك. |

## ما بداخل المستودع

يعمل مع **Claude Code** و **Cursor** و **GitHub Copilot** وأي مساعد ذكاء اصطناعي يدعم الوكلاء والمهارات. قم بالتثبيت كإضافة أو انسخ المكونات يدويًا.

```
agentkits-marketing/
|-- .claude-plugin/      # ملفات البيانات الوصفية للإضافة والسوق
|   |-- plugin.json            # بيانات الإضافة ومسارات المكونات
|   |-- marketplace.json       # كتالوج السوق لـ /plugin marketplace add
|
|-- .claude/
|   |-- agents/          # 18 وكيل تسويقي متخصص
|   |   |-- attraction-specialist.md    # توليد العملاء المحتملين، تحسين محركات البحث، صفحات الهبوط
|   |   |-- lead-qualifier.md           # تقييم وتصنيف العملاء المحتملين
|   |   |-- email-wizard.md             # تسلسل البريد الإلكتروني، الأتمتة
|   |   |-- sales-enabler.md            # ضمانات المبيعات، بطاقات المعارك
|   |   |-- continuity-specialist.md    # الاحتفاظ، إعادة المشاركة
|   |   |-- upsell-maximizer.md         # توسيع الإيرادات
|   |   |-- copywriter.md               # نصوص عالية التحويل
|   |   |-- conversion-optimizer.md     # متخصص تحسين التحويل
|   |   |-- seo-specialist.md           # تحسين محركات البحث
|   |   |-- brand-voice-guardian.md     # الاتساق في هوية العلامة التجارية
|   |   |-- ...والمزيد
|   |
|   |-- commands/        # 93 أمر مصنف حسب الفئة
|   |   |-- campaign/    # /campaign:plan, /campaign:brief, /campaign:analyze
|   |   |-- content/     # /content:blog, /content:landing, /content:email
|   |   |-- seo/         # /seo:keywords, /seo:audit, /seo:programmatic
|   |   |-- cro/         # /cro:page, /cro:form, /cro:popup, /cro:signup
|   |   |-- growth/      # /growth:launch, /growth:referral, /growth:free-tool
|   |   |-- ...والمزيد
|   |
|   |-- skills/          # 28 مهارة تسويقية
|   |   |-- marketing-psychology/       # 70+ نموذج ذهني
|   |   |-- marketing-ideas/            # 140+ استراتيجية SaaS
|   |   |-- page-cro/                   # تحسين صفحات الهبوط
|   |   |-- copywriting/                # نصوص تسويقية
|   |   |-- programmatic-seo/           # توليد صفحات على نطاق واسع
|   |   |-- pricing-strategy/           # استراتيجية التسعير والتعبئة
|   |   |-- ...والمزيد
|   |
|   |-- workflows/       # سير العمل التسويقي الأساسي
|       |-- primary-workflow.md         # دورة حياة الحملة
|       |-- sales-workflow.md           # من العميل المحتمل إلى العميل
|       |-- crm-workflow.md             # دورة حياة جهة الاتصال
|
|-- docs/                # الوثائق والأدلة
|-- marketplace.json     # تكوين السوق المستضاف ذاتيًا
```

## التثبيت

### الخيار 1: سوق إضافات Claude Code (موصى به لـ Claude Code)

ثبّت مباشرة عبر نظام الإضافات في Claude Code — بدون تهيئة يدوية:

```bash
# إضافة السوق
/plugin marketplace add aitytech/agentkits-marketing

# تثبيت المجموعة الكاملة (18 وكيل، 28 مهارة، 93 أمر)
/plugin install agentkits-marketing@agentkits-marketing
```

يمكنك أيضًا تثبيت المكونات بشكل فردي:

```bash
/plugin install agentkits-marketing-skills@agentkits-marketing    # المهارات فقط
/plugin install agentkits-marketing-agents@agentkits-marketing    # الوكلاء فقط
/plugin install agentkits-marketing-commands@agentkits-marketing  # الأوامر فقط
```

أعد تشغيل Claude Code بعد التثبيت.

---

### الخيار 2: التثبيت عبر npx (جميع المنصات)

أمر واحد لتثبيت 18 وكيل، 28 مهارة، 93 أمر:

```bash
npx @aitytech/agentkits-marketing install
```

**التثبيت الخاص بمنصة معينة:**

```bash
npx @aitytech/agentkits-marketing install --platform claude    # Claude Code
npx @aitytech/agentkits-marketing install --platform cursor    # Cursor IDE
npx @aitytech/agentkits-marketing install --platform windsurf  # Windsurf
npx @aitytech/agentkits-marketing install --platform cline     # Cline
npx @aitytech/agentkits-marketing install --platform copilot   # GitHub Copilot
npx @aitytech/agentkits-marketing install --platform all       # جميع المنصات
```

**أوامر CLI أخرى:**

```bash
npx @aitytech/agentkits-marketing --help        # إظهار جميع الأوامر
npx @aitytech/agentkits-marketing list-ides     # سرد بيئات التطوير المدعومة
npx @aitytech/agentkits-marketing list-modules  # سرد الوحدات المتاحة
npx @aitytech/agentkits-marketing update        # تحديث التثبيت الحالي
```

### الخيار 4: التثبيت اليدوي

انسخ المكونات الفردية إلى تكوين Claude الخاص بك:

```bash
# استنسخ المستودع
git clone https://github.com/aitytech/agentkits-marketing.git

# انسخ الوكلاء
cp agentkits-marketing/.claude/agents/*.md ~/.claude/agents/

# انسخ الأوامر
cp -r agentkits-marketing/.claude/commands/* ~/.claude/commands/

# انسخ المهارات
cp -r agentkits-marketing/.claude/skills/* ~/.claude/skills/

# انسخ سير العمل
cp -r agentkits-marketing/.claude/workflows/* ~/.claude/workflows/
```

## البدء السريع

### إطلاق حملة

```bash
# البحث والتخطيط
/research:market "SaaS productivity tools"
/competitor:deep "competitor.com"
/campaign:plan "Q1 Product Launch"

# إنشاء المحتوى
/content:landing "new feature" "target audience"
/content:email "product launch" "trial users"
/content:blog "feature announcement" "primary keyword"

# التحسين
/cro:page "landing page for conversion"
/seo:optimize "content.md" "target keyword"
```

### إنشاء المحتوى

```bash
/content:good "Blog post about AI marketing"
/content:editing "polish this draft"
/seo:keywords "ai marketing automation"
```

### تحسين التحويل

```bash
/cro:page "homepage conversion audit"
/cro:form "lead capture optimization"
/cro:signup "registration flow"
/test:ab-setup "headline variations"
```

### النمو والاستراتيجية

```bash
/marketing:ideas "SaaS product"
/marketing:psychology "pricing objections"
/growth:launch "Product Hunt strategy"
/pricing:strategy "tier structure"
```

## مسارات التعلم

### المسار 1: البدء السريع (30 دقيقة)
للمسوقين ذوي الخبرة - انتقل مباشرة إلى الإنتاج:
```bash
/campaign:plan "Your campaign"
/content:good "Your content"
/cro:page "Your landing page"
```

### المسار 2: مهارة محددة (15-30 دقيقة لكل مهارة)
تعلم مهارات محددة حسب الحاجة:

| الهدف | الأوامر |

| **تحسين التحويلات** | `/cro:page`, `/cro:form`, `/marketing:psychology` |
| **كتابة نصوص أفضل** | `/content:good`, `/content:editing` |
| **إطلاق منتج** | `/growth:launch`, `/campaign:plan` |
| **تحسين التسعير** | `/pricing:strategy` |
| **توسيع نطاق تحسين محركات البحث** | `/seo:programmatic`, `/seo:schema` |
| **تصميم الإحالات** | `/growth:referral` |
